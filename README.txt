[v23] 이미지 파일 이름 규칙
- WORKS   : 연도-분야-영문이름-번호.webp   예) 2026-ld-cherry-mat-01.webp
  (연도 = 프로젝트 연도, 분야 = 첫 번째로 체크한 분야)
- ACTIVITY: event-연도-영문이름-번호.webp  예) event-2026-holosma-01.webp
- HOME    : home-hero-날짜.webp            예) home-hero-20261007.webp
- 썸네일은 assets/images/thumbs에 같은 이름으로, 저작권 문구 없는 원본은 이름 끝에 -clean이 붙습니다.
- 영문 이름은 편집기의 각 프로젝트·행사 '영문 이름 (파일 이름용)' 칸에서 정합니다.
  비워두면 기존 ID를 쓰고, 새 프로젝트는 work / 새 행사는 event가 들어갑니다.
- 번호는 자동으로 다음 빈 번호가 붙고, 이미 있던 파일은 절대 덮어쓰지 않습니다.
- 기존 숫자 이름(6513 등) 17개도 이 규칙으로 모두 바꿨습니다.

[v23] 편집기 사용 편의
- WORKS·ACTIVITY 목록에 썸네일, 이미지 장수, 숨김 표시가 보입니다. 위쪽 검색칸으로 프로젝트·행사를 찾을 수 있습니다.
- 빠른 업로드(기본 켜짐): 여러 장을 한 번에 올리면 자르기 창 없이 바로 추가됩니다.
  상세 이미지는 긴 변 2800px WebP, 썸네일은 4:3으로 자동 생성(세로 그림은 위쪽 얼굴 부분 기준).
  마음에 안 드는 것만 '썸네일 자르기'/'상세 자르기'로 고치면 됩니다. 끄면 예전처럼 한 장씩 자르기 창이 뜹니다.
- 업로드 칸에 이미지 파일을 끌어다 놓아도 올라갑니다.
- 편집기 이미지들은 화면에 보일 때만 불러와서 이미지가 많아도 가볍게 열립니다.

[v23] 문의 폼 → FormSubmit (참고 이미지 첨부)
- Web3Forms는 파일 첨부가 유료라서, 무료로 첨부가 되는 FormSubmit으로 바꿨습니다.
- 방문자는 참고 이미지를 최대 5장(합계 10MB) 올릴 수 있고, 메일 첨부파일로 옵니다.
  2MB가 넘는 그림은 자동으로 줄여서(긴 변 2400px JPG) 보냅니다. 끌어다 놓기·붙여넣기 가능.
- 처음 설정: 사이트에서 시험 문의를 한 번 보낸 뒤, 메일로 온 FormSubmit 확인 메일의 'Activate Form'을 누르면 끝.
- 선택: 활성화 후 받은 무작위 코드를 편집기 HOME 탭 'FormSubmit 코드'에 넣고 저장하면 코드에서 이메일 대신 그 코드가 쓰입니다.
- Web3Forms Access Key는 더 이상 쓰지 않습니다.
